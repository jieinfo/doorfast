# 主机模式住宅组播成员关系

现场 MT8157 抓包显示，门口机对 `IS:2-1-1901-1` 的来电以 UDP/8300
发送至 `238.0.203.193`。该地址由本机逻辑身份确定性推导，而不是由 DHCP
或门口机登录下发。

Doorfast 在主机模式启动时根据配置的 `IS:` 地址推导住宅组播地址，在
`indoor_ipaddr` 对应的本地接口加入该 IPv4 组播组并绑定 UDP/8300。进程停止或
启动后续阶段失败时关闭该套接字；关闭会释放内核的成员关系。

这一步使启用 IGMP snooping 的交换机能够将该住宅组播流量转发给主机接口。
它只证明本机已请求加入组播组，不能证明门口机已呼叫、交换机已转发，或通话
业务已被对端接受。应在实机上以 `ip maddr show dev <host-interface>` 和一次门口机
来电抓包验证。
