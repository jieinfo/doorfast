# 兼容性矩阵

状态依据可复现的代码测试和贡献者自有设备证据，而不是旧闭源程序中出现过的品牌名称。

| 设备系列 | 被动识别 | 控制操作 | 证据状态 | 说明 |
|---|---:|---:|---|---|
| GVS（视声） | 设计中 | 未启用 | 自有设备离线 PCAP + 应用行为线索 | 已观察到 UDP 帧包络、会话生命周期和控制响应；尚未提交匿名化夹具或实现解析器。 |
| 狄耐克 | 基础 SIP 会话解析（历史基础） | 未启用 | 静态线索 + 主机测试 | 旧包可见相关 SIP 与电梯模板；不属于 GVS 主线。 |
| 大华 | 未实现 | 未启用 | 仅静态线索 | 旧包含品牌分支和模板，不构成兼容验证。 |
| 海康威视 | 未实现 | 未启用 | 仅静态线索 | 同上。 |
| 立林 V2/V3 | 未实现 | 未启用 | 仅静态线索 | 同上。 |
| ABB、冠林、TP-Link 与其他旧包品牌 | 未实现 | 未启用 | 仅静态线索 | 需要独立的脱敏夹具和实体结果。 |

## 状态含义

- **仅静态线索**：旧样本中存在名称、字段或模板；不能推断网络交互正确。
- **设计中**：已有来自贡献者自有设备的离线证据，但尚未形成匿名化夹具和可执行解析器。
- **基础 SIP 会话解析**：Doorfast 可在不发送报文的情况下识别有限的会话事件。
- **控制已验证**：仅在满足贡献规范的请求、响应、回放和实体结果门槛后标记；当前没有任何条目达到该状态。
